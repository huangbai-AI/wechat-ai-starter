## 没有混为一谈的部分

核心消息收发逻辑来自此前已跑通的微信 AI 接入实践。本次新做中文面板和通用配置时，没有改动原在用微信的登录或接收地址；**因此不能把离线测试写成这套新面板已在所有真实账号上完成联调。**

不同读者的微信通道权限、模型权限与网络，需要按教程最后的两条消息自行验收。Mac 本机界面已检查；Windows / Linux 的自动检查结果见仓库 Actions，不能视为已在每种桌面环境手动安装过。

## 如何复核

在项目目录执行：

```sh
python3 -m unittest discover -s tests -v
```

Windows 可用 `py -3 -m unittest discover -s tests -v`。测试使用临时文件和模拟外部服务，不需要真实密钥，不会绑定微信接收地址。

项目自动检查入口：[GitHub Actions](https://github.com/huangbai-AI/wechat-ai-starter/actions)。
