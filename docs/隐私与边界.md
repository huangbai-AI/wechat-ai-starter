# 消息和密钥会去哪里？

[返回主教程](../README.md)

## 这份项目实际做什么

接收 WechatApi 传来的消息，检查是否是你允许的私聊或群内 @，把符合条件的文字和短期问答记忆交给你选择的大模型，最后调用微信通道发送文字。

本项目面板只在本机打开；临时公网通道只连接消息接收服务，不把操作面板公开到网络。

## 数据经过哪些服务

- WechatApi 负责微信连接与消息收发；该平台能处理到的微信数据范围，以其服务权限和条款为准。
- Cloudflare 临时通道承载微信服务商传来的消息。允许名单是本机程序收到之后才判断的，不能理解为其他消息绝不经过通道。
- 只有本项目判定合格的问题、必要的问答记忆与助手设定会送到你配置的模型服务商。
- 查通讯录按钮会向微信服务商读取编号和昵称，在本机面板供你选；本项目不把整份通讯录存盘或交给大模型。

## 本机保存什么

`runtime/config.json` 保存微信通道密钥、模型密钥和配置。它不是加密保险箱，不要共享整个运行目录，也不要把它放进公开仓库。

`runtime/queue.sqlite3` 保存排队状态、消息编号、对象编号及短期问答记忆。处理结束后会清空队列表中的消息正文，但问答记忆另行保留：每个会话最多 20 条，一问一答算两条；同一群共用记忆。群成员标识经处理后用于区分发言者，这不等于完全匿名化。

“最多 20 条”是每个会话的记忆上限，不是所有本机记录的总量上限；编号、累计状态等仍会保留。清除方法见[常见问题](常见问题.md)。

## 不在本版范围

没有自动同步飞书知识库，没有联网搜索，没有语音、图片或文件理解，没有自动接管全部联系人，没有扫码登录自动恢复，没有云端常驻部署。源码中的资料检索模块保留为后续开发基础，面板不会启用或自动获取任何私人知识库。

微信账号可能掉线，第三方服务可能变动，模型可能说错。此项目用于个人学习和小范围试用，不宣称微信官方认可，也不承诺防封或持续在线。

让参与者知道这是 AI 助手，避免发送不必要的私人资料。发生异常先暂停，不要通过群内大量发送来测试。
