# 常见问题：按你停住的位置查

[返回主教程](../README.md)

## 还没打开面板

**双击没有反应 / 闪退**：按[安装指南](安装指南.md)在项目文件夹打开运行窗口，执行启动命令，就能看到提示。先确认 Python 已安装，而不是重装微信。

**浏览器打不开**：确认运行窗口仍在，地址为 `http://127.0.0.1:8818`，前面是 http，不是 https。

**提示端口占用**：可能已经打开过一个面板。先用已有窗口；不要一次启动多份程序。

## 信息不知道从哪找

| 信息 | 正确来源 | 不能拿什么替代 |
| --- | --- | --- |
| 微信终端 appId | WechatApi 中当前登录终端 | 微信公众号 AppID、模型 ID |
| 微信通道密钥 | WechatApi 后台“访问控制” | 大模型密钥 |
| 机器人自己的 wxid | “读取机器人身份”，或后台账号详情 | 昵称、手机号、可修改的微信号 |
| 测试好友 wxid | 通讯录里点选测试好友 | 机器人的 wxid |
| 群 ID | 通讯录里点选目标群，以 @chatroom 结尾 | 群名称 |
| 大模型密钥 | 模型服务商开放平台 | 微信通道密钥、聊天网站登录密码 |

**读取机器人身份失败**：先核对 appId 和 token 是否对应同一个后台的可用终端，再确认该微信在线。

**找不到好友**：确认两个微信号已加好友，再读取；联系人多时点击下一页。只显示编号、昵称读取不成功时，不要靠猜选择，先到微信接入后台核对。

**找不到群**：先在手机微信里打开群设置，将群保存到通讯录，然后回来重新读取。服务商的通讯录接口只返回相应已保存的群。[官方说明](https://post.wechatapi.net/contacts/fetchcontactslist)

## 模型检查不通过

- 提示密钥或地址未通过验证：核对服务商、地域、项目是否配套。
- 提示额度不足或请求过多：到模型后台看余额、用量限制，稍后再试。
- 提示地址或模型未找到：别把网页地址当基础地址；不要重复填写 `/chat/completions`。
- 提示参数不支持：高级参数先按所选模型文档核对；未确认支持时关闭 JSON 模式。
- 通用“操作未完成”：先检查网络；Mac 用户检查 Python 证书安装步骤。不要把整份含密钥的配置发给别人。

## 临时通道连不上

先确认安装了 cloudflared，名字和位置见[安装指南](安装指南.md)。然后检查电脑能否访问外网及 Cloudflare 服务，稍后再点一次连接。

临时通道没有可用性承诺，也可能受当前网络限制。如果一直失败，本版无法靠本机继续接收微信消息。可以换到允许访问该服务的网络，或者后续改成服务器与固定地址；**不要把微信反复退出重登当成解决网络问题的方法。**

## 微信已连接，但没有回复

按顺序只看三件事：

1. **收到消息有没有增加？**没有：查微信是否在线、通道是否仍连接，以及同一 token 是否被别的工具重新设置了接收地址。
2. **符合回复条件有没有增加？**没有：查允许好友、允许群、真正的 @。只测试普通文字；过旧的消息、机器人自己的消息也会被忽略。
3. **是不是已开启自动回复，并在开启后发了新消息？**检查阶段的消息不会补发。别只盯着之前的测试消息等待。

同一条消息如果被服务商重复投递，程序只处理一次。并发消息较多时会排队，发送之间至少间隔约 3 秒；超过 5 分钟的旧消息会跳过。这是小范围入门版，不适合群内高频刷屏。

## “需要检查”是什么意思？

它代表某次处理失败，或发送结果没能确认。**先在原聊天窗口看是否已经收到**，避免同一句重复发送。确认没收到且模型/通道恢复后，请对方重新发一条新问题。

模型连接失败可能完全不回；模型返回格式异常时会尝试一次修复，仍异常就发一句简短兜底提示。这个兜底不代表模型正常，先回面板重新检查模型。本版没有后台批量补发按钮。

## 为什么会发出一大段“分析、候选回答”？

本版要求模型返回最终答复，并拦截常见草稿格式；模型提供独立思考字段时不读取该字段。若仍出现异常，先暂停，核对是否使用正确模型和参数，再反馈问题。文字检查不能保证拦截任何一种模型输出。

## 暂停、换工具与删除资料

- 只是休息：点击暂停。恢复前按面板提示检查。
- 要切回原来的机器人：关闭本项目只能停止本项目，**不会自动恢复原工具的接收地址**。需要回原工具重新绑定；关闭本项目也不会主动退出微信。
- 清空问答记忆：先关闭本项目运行窗口，再删除本项目 `runtime/queue.sqlite3`。这也会清空去重记录与累计状态；重启后重新验证再开。
- 清除本机配置：关闭本项目后删除它自己的 `runtime` 文件夹，下次需重新填写。不要误删其他机器人的目录。

## 怎么求助最省时间？

在 [GitHub 问题区](https://github.com/huangbai-AI/wechat-ai-starter/issues)写清：系统、停在哪一站、面板提示、三个计数是否增加。截图前遮住密钥、个人编号和聊天内容。不要上传 runtime 文件夹或完整消息接收地址。
