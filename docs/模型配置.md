# 模型怎么填：三项信息必须配套

[返回主教程](../README.md)

**本项目使用 OpenAI 兼容聊天格式，可以连接不同品牌的大模型。**它不是一个不限品牌、无限制的万能转换器：模型需要接受聊天请求，并在正文中给出答案。

## 通用方法

到服务商开放平台找“API Key”“模型列表”“OpenAI 兼容”这三处。把基础地址、密钥和模型 ID 填进面板。若存在地域、工作空间、子账号，三项应属于同一套可用配置。

不要把浏览器中模型聊天页面的网址填到调用地址里，也不要把完整的 `/chat/completions` 请求地址填进基础地址。高级设置中的附加参数，只有模型文档明确要求时才填写。

## 示例 A：Kimi 中国站

以下是文档核对时的一组配置示例，不代表账号必然已开通该模型，也不是唯一可选模型。

| 字段 | 填写内容 |
| --- | --- |
| 大模型调用地址 | `https://api.moonshot.cn/v1` |
| 模型名称 | `kimi-k2.6`（需确认账号可调用） |
| 大模型密钥 | 自己在 Kimi 开放平台创建的 API Key |
| 高级设置 → 模型附加参数 | `{"thinking":{"type":"disabled"},"max_tokens":2048}` |
| JSON 输出模式 | 首次可不勾选；确认模型支持后再开 |

关闭思考的参数来自这个模型的文档，不能复制给所有品牌。[官方 Kimi K2.6 文档](https://platform.kimi.com/docs/guide/kimi-k2-6-quickstart)

## 示例 B：千问 / 阿里云百炼

进入百炼的模型调用说明，选择自己开通的地域与工作空间，复制该空间对应的**兼容接口基础地址**；再复制该空间可用的模型 ID 和 API Key。

官方文档中的一种地址形式是：

```text
https://你的工作空间ID.cn-beijing.maas.aliyuncs.com/compatible-mode/v1
```

这一行只是解释地址长什么样。不要把“你的工作空间ID”几个字直接粘进去，也不要把北京示例用于别的地域。以自己后台的完整地址为准。

模型名称填写当前控制台列出的可调用模型 ID。高级参数先保留 `{}`；需要关闭思考或设置回答长度时，按所选模型文档填写，不套用 Kimi 的参数。[官方兼容接口说明](https://help.aliyun.com/zh/model-studio/compatibility-of-openai-with-dashscope)

## 其他服务商

同样先确认是否支持这种兼容格式。技术上，本项目调用 `/chat/completions`，使用系统与用户消息，读取 `choices[0].message.content`；仅支持 `/messages` 或 `/responses` 的服务不能直接代入。

项目会要求模型把最终答复放进一个规定字段，再取出文字发到微信。你不需要手工编写这个格式。点击“检查模型”失败时，先确认模型支持这类输出要求，而不是连续切换随机参数。

## 额度和会员有什么关系？

模型聊天网页的会员、编程工具套餐、开放平台 API 额度，可能是不同产品。先在服务商文档里确认自己的套餐允许这种程序调用；不要因为手上已有一串密钥就假定它可用于所有用途。

检查模型和自动回复都会消耗模型额度；异常输出的自动修复可能额外调用一次。先在服务商后台设置合适的用量限制，再小范围测试。本文不锁定模型价格，费用以服务商实时账单为准。
